Dicas para stencils mais limpos

  • Fotografe ou escaneie reto, com luz uniforme, com o desenho preenchendo o quadro.
  • Use Desenho para sketches e flash. Use Foto para imagens com sombreado suave.
  • Aumente Remover pontinhos para limpar ruído. Diminua a Sensibilidade se o sombreado virar linhas.
  • Se as linhas ficarem fracas na sua impressora, tente uma linha mais grossa e teste primeiro no papel.
