Conseils pour des stencils plus nets

  • Photographiez ou scannez à plat, sous une lumière uniforme, avec le dessin qui remplit le cadre.
  • Utilisez Dessin pour les croquis et les flashs. Utilisez Photo pour les images aux ombres douces.
  • Augmentez Supprimer les impuretés pour nettoyer le bruit. Baissez la Sensibilité si les ombres se transforment en lignes.
  • Si les lignes paraissent pâles sur votre imprimante, essayez un trait plus épais et testez d'abord sur papier.
