Tattoo stencil size: how to print at true size

Last updated: November 25, 2026

The short answer

To print a tattoo stencil at true size, decide the width in millimetres, divide by 25.4 and multiply by 300 to get the pixel width at 300 dpi, then print at 100 percent with no scaling. A 100 mm stencil needs about 1181 pixels. Confirm the result with a ruler on the printout.

Why stencil size is easy to get wrong

A digital image has no physical size of its own. It is a grid of pixels, and the size on paper depends on how many pixels are placed in each inch. That is the dpi, short for dots per inch. The same file can print as a stamp or as a poster.

For a tattoo stencil that is a problem, because the artwork has to land on skin at exactly the size the client agreed. Print software often guesses, scales the image to fit the page, or opens the file at 72 or 96 dpi and makes it much bigger than you expected. Getting stencil size right means settling the size once, in millimetres, and making sure the file carries it through to the printer.

Millimetres to pixels at 300 dpi

There are 25.4 millimetres in an inch. So the pixel width you need is:

pixels = millimetres ÷ 25.4 × 300

Here is the result for common widths, rounded to the nearest pixel:

You do not need to do this by hand. In the tool you type the width in millimetres and it shows the size at 300 dpi next to it. The table is here so you can see why a small file cannot be printed large without looking soft.

Why 300 dpi

300 dpi is the usual target for printed images that will be looked at closely. At that density a thin line still prints as a clean, continuous stroke. Lower densities start to show stair-stepped edges on curves, and a stencil is almost all curves.

More is not always better. Bigger files are slower to open and print, and a thin stencil line gets no sharper than your printer can draw it. 300 dpi is a sensible balance for stencil work and is what Skinstencil uses for its true-size output.

How the 300 dpi value inside the PNG helps

A PNG file can carry a physical size, stored as pixels per metre in a small block of data in the file. Many programs read it and use it to open the image at that size. If the value says 300 dpi, a 1181 px wide image opens at about 100 mm wide, with no manual resizing.

When the value is missing, programs fall back on a default, which is often 72 or 96 dpi. At 72 dpi that same 1181 px image would open about 416 mm wide, more than four times as large. That is a common reason a stencil comes out of the printer far too big.

Printing at true size

A short routine that avoids surprises:

  1. Set the width in the tool. Enter the width on skin in millimetres. The tool shows the equivalent size at 300 dpi.
  2. Download the PNG. With a day pass or Pro, the file stores the 300 dpi size, so most programs open it at the right width.
  3. Open it in your print dialog. Choose actual size or 100 percent. Turn off fit to page, shrink to fit and fill page.
  4. Print a test on plain paper. Use ordinary paper for the test, not your transfer material.
  5. Measure the printout. Lay a ruler across the widest part and compare it with the width you set. Adjust and reprint if it is off.

Check with a ruler, every time

Printers and drivers change settings without telling you, especially after an update or on a shared computer. A ruler removes the guesswork. Measure the full width of the design on the printout, edge to edge of the artwork and not the paper, and compare it with the millimetres you set.

The tool also draws a true-size ruler that follows the print width you set, so you can see the intended scale on screen. Screens differ, so that ruler is only a guide and the ruler on the printout is the one that counts.

If the printout is off by a consistent percentage, a scaling option is probably switched on. If it is off by a large factor, the program probably opened the file at 72 or 96 dpi.

Why free downloads are capped at 800 px

Free downloads carry a watermark and are limited to 800 px. At 300 dpi, 800 px is about 68 mm, which is fine to judge a design but small for a stencil on skin. Larger stencils need more pixels to stay sharp, and that is what a day pass or Pro unlocks: no watermark, up to 4000 px, which is about 339 mm wide at 300 dpi, and the 300 dpi size stored in the file.

Questions

How many pixels do I need for a 100 mm stencil?

About 1181 pixels wide at 300 dpi. The formula is millimetres divided by 25.4, multiplied by 300.

Why is my stencil printing too big?

Often the program opened the PNG at 72 or 96 dpi because no size was stored in the file, or a fit to page option scaled it up. Print at 100 percent and set the width yourself, or use a file with the 300 dpi size stored in it.

What does the 300 dpi value inside the PNG do?

It tells print software the physical size of the image, so it can open at the width you set instead of guessing. Day pass and Pro downloads include it.
